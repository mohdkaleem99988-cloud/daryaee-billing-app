DARYAEE ENTERPRISES BILLING APP — STARTER VERSION

Included:
- Customer name, mobile and address
- Automatic bill number and date
- Six columns: S.No., Material Name, Quantity, Unit, Rate, Total Amount
- Unit choices: MTR, FIT, NO, PCS, SET, KG, BOX, ROLL, plus custom unit
- Automatic line total and grand total
- Save bill and bill history in the same mobile browser
- Print / Save as PDF
- WhatsApp text sharing
- Offline cache after first online load (when hosted on HTTPS)

IMPORTANT:
This is a starter web app. To install it like an Android app, it must first be uploaded to a secure HTTPS website/hosting. Open that website in Chrome, then use Chrome menu > Add to Home screen / Install app.
Bills are stored in the browser on that phone. Do not clear browser site data or switch browsers if you want to keep the saved bills. Make regular PDF backups.
